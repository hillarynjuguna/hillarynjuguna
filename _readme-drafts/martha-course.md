# Martha Course

A 6-module human development course built on the DCFB (Distributed Cognition Fear Bypass) framework.

## What This Is

Martha is a structured transformation curriculum that teaches the DCFB framework as a lived practice. Each module addresses a layer of the cognitive architecture that fear colonizes — from the structural understanding of fear itself, through distributed cognition and field stewardship, to the full Recursive Sovereign Project Space (RSPS) topology.

Waitlist-first. Full content gated behind payment. Founding price: RM 430.

## Modules

1. **Fear as Architecture** — DCFB foundation: fear is a structure, not a feeling
2. **The Middle Space** — Pre-symbolic substrate where new relational forms originate
3. **Distributed Cognition** — Action through field resonance rather than individual volition
4. **The Ache-to-Echo Dynamic** — How precision-weighted prediction errors become field signals
5. **Field Stewardship** — Maintaining coherence in high-interference environments
6. **RSPS Topology** — Recursive Sovereign Project Space: building a sustainable cognitive architecture
