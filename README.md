## What this work is for

A lot of AI discussion splits capability, governance, cognition, and organization into separate lanes. This work assumes they are coupled.

When cognition is distributed across people, models, memory, and institutions, governance can’t be policy text alone—it must include **structure, routing, reversibility, accountability, and provenance**.

That coupling problem is the center of this profile.
