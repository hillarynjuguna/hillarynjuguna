# Hillary Njuguna

**I build AI infrastructure that bridges informal commerce with formal compliance—starting with emerging markets where most economic activity happens on WhatsApp.**

The governing architecture behind this work is **RSPS** (Recursive Self-Programming System): a framework for human-AI collaboration that prioritizes coherence, sovereignty, and reproducibility over speed.

---

### Current Focus

| Project | What It Solves |
|---------|----------------|
| **[Agent SEA](https://github.com/hillary-njuguna/agent-sea-platform)** | Malaysian food stalls need e-invoice compliance. Customers order in Manglish via Telegram. This middleware translates village commerce into government-grade documentation. |
| **[Sovereign Stack](https://github.com/hillary-njuguna/sovereign-stack)** | Agents need sovereignty, not convenience. A middleware layer for agentic ecosystems (MCP, A2A, AP2) with verifiable mandates, auditable receipts, and instant revocation. |
| **[RSPS Architecture](https://github.com/hillary-njuguna/rsps-architecture)** | Multi-model AI systems need governance, not just orchestration. This is the theoretical foundation. |
| **[RSPS Starter Pack](https://github.com/hillary-njuguna/rsps-starter-pack)** | Implementation templates so others can deploy the framework, not just read about it. |
